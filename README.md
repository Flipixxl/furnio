# Furnio — сайт для продажи мебели

Качественный магазин мебели на **Flask + SQLite** с собственным генератором SVG-изображений товаров.

## Возможности

- Каталог с фильтрами (категория, цена, наличие) и сортировкой
- Поиск по названию, описанию и материалам
- Страницы товаров с характеристиками и похожими товарами
- Корзина и оформление заказа (сессия, SQLite)
- Страницы «О нас» и «Контакты» с формой обратной связи
- Адаптивный дизайн, автогенерация картинок товаров (SVG)
- Стартовые данные: 6 категорий, 24 товара

## Запуск

```bash
cd "C:\Users\krugl\python projects\furniture_shop"

# создать виртуальное окружение (уже создано в .venv)
py -m venv .venv
.venv\Scripts\activate

# установить зависимости
pip install -r requirements.txt

# запустить сервер
python app.py
```

Откройте http://127.0.0.1:5000 в браузере.

При первом запуске автоматически создаётся база `instance/furniture.db` и генерируются изображения в `static/img`.

## Структура

```
furniture_shop/
├── app.py          # Flask-приложение и маршруты
├── seed.py         # схема БД, стартовые данные, генерация SVG
├── requirements.txt
├── templates/      # Jinja2-шаблоны
└── static/
    ├── style.css   # дизайн
    ├── app.js      # интерактив (меню, фильтры, корзина)
    └── img/        # сгенерированные изображения
```
