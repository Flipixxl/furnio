# Furnio — магазин мебели на Flask

> **Проект-портфолио: Олег Круглов**

Живой, полностью рабочий интернет-магазин мебели. Собственное производство «в коде»: от базы данных и генератора изображений до оформления заказов и деплоя.

**Демо:** https://furnio.onrender.com  
**Исходный код:** https://github.com/Flipixxl/furnio

> **Доступность:** сервер развёрнут на Render (бесплатный тариф) и работает круглосуточно. После ~15 минут без запросов инстанс «засыпает» — первое открытие сайта занимает 30–60 секунд (холодный старт), затем страницы открываются быстро.

---

## Стек и технологии

- **Python / Flask 3** — сервер, маршруты, сессии
- **SQLite** — каталог, корзина, заказы
- **Jinja2** — шаблоны (12 страниц)
- **Чистый CSS** (без фреймворков) — полный дизайн-система: адаптив, анимации, тёмные секции
- **JavaScript (vanilla)** — быстрый просмотр, корзина без перезагрузки, переключение «сетка/список», таймер акции
- **Реальные фото товаров** — 24 фотографии мебели (свободная лицензия Wikimedia Commons) привязаны к товарам
- **Автогенерация SVG** — фирменные изображения категорий и обложек создаются кодом
- **Деплой:** GitHub → Render (бесплатный тариф), gunicorn. Автодеплой при каждом пуше в `main`.

## Возможности

- Каталог с фильтрами (категория, цена, наличие) и 5 видами сортировки
- Поиск по названию, описанию и материалам — регистронезависимый, с кириллицей
- Страницы товаров: характеристики, гарантия, похожие товары
- Корзина (AJAX) и оформление заказа с сохранением в БД
- Быстрый просмотр товара в модальном окне
- Lookbook «Интерьеры», блок материалов, FAQ, подписка, таймер акции
- Адаптивная вёрстка (мобильные/планшеты/десктоп)
- 6 категорий, 24 товара со стартовыми данными

## Проверка качества

Прогон автотестов: все страницы, поиск (регистры, кириллица, материалы, пустой результат, XSS), фильтры, сортировки, корзина (включая защиту от невалидных данных), заказы и оформление — **41 проверка, все проходят**.

## Запуск локально

```bash
cd "C:\Users\krugl\python projects\furniture_shop"

# создать виртуальное окружение (уже создано в .venv)
py -m venv .venv
.venv\Scripts\activate

# установить зависимости
pip install -r requirements.txt

# запустить сервер
python app.py
```

Откройте http://127.0.0.1:5000 в браузере.

При первом запуске автоматически создаётся база `instance/furniture.db` и генерируются изображения в `static/img`.

## Структура

```
furniture_shop/
├── app.py          # Flask-приложение и маршруты
├── seed.py         # схема БД, стартовые данные, генерация SVG
├── requirements.txt
├── render.yaml     # конфигурация деплоя на Render
├── templates/      # Jinja2-шаблоны
└── static/
    ├── style.css   # дизайн-система
    ├── app.js      # интерактив (меню, фильтры, корзина, быстрый просмотр)
    └── img/
        ├── products/   # реальные фото товаров (24 шт.)
        └── *.svg       # сгенерированные изображения
```
